# GoSnack: Aplicativo de Gestão de Lanchonetes Escolares

<!-- Introdução ------------------------------------------------------------ -->

Este projeto é uma recriação de um [antigo projeto acadêmico](https://github.com/PI-ChatBot/chatbot).

O GoSnack é um aplicativo de gestão de lanchonetes escolares. Ele funciona como um sistema completo de autoatendimento, dividido em duas frentes principais: um aplicativo cliente para pedidos e retiradas, e um painel administrativo web para controle das unidades, cardápios e estoques.

- **App Cliente (Mobile):** Desenvolvido em Flutter utilizando o gerenciador de estados Bloc.
- **Dashboard Admin (Web):** Desenvolvido com React, Next.js e Shadcn.
- **Back-end e Infraestrutura:** Supabase hospedado na nuvem, utilizando PostgreSQL, Auth, Storage e Edge Functions.
